# 멤버 갤러리

초대받은 멤버만 사진·영상을 올리고 댓글로 소통하는 비공개 커뮤니티 웹앱입니다.
단일 HTML 파일(`index.html`)이며, Supabase(Auth · Postgres · Storage)를 백엔드로 사용합니다.

- 사이트: https://dawis2-kr.github.io/member-gallery/
- 입장: 회원가입 → 이메일 확인 → 초대 코드 입력(`redeem_invite`) → 멤버 승인
- 미디어: 비공개 버킷 `media`, 파일당 50MB, 1시간 유효 Signed URL로 표시
- 비밀번호 재설정: 로그인 탭의 "비밀번호를 잊으셨나요?" → 메일 링크(`type=recovery`) → 새 비밀번호 입력 → 바로 피드로 입장

## 알아둘 점: 메일 발송 한도

Supabase 기본 메일 서비스는 **프로젝트 전체에서 시간당 2통**만 보냅니다(가입 확인 메일 포함).
비밀번호 재설정 메일도 같은 한도를 쓰므로, 가입 확인 메일을 막 보낸 직후라면 `요청이 너무 잦습니다`
안내가 뜰 수 있습니다. 이때는 약 1시간 뒤 다시 요청하면 됩니다. 한도를 늘리려면
Supabase 대시보드에서 커스텀 SMTP를 설정해야 합니다.
